# Simple Bank Account #2 — Menu Loop

Language: Python 3

## Problem statement (as given to students)

Simple Bank Account #2 — Menu Loop

เริ่มยอด 0 วนเมนูรับคำสั่งจนกว่าจะเลือก 4
1 = Deposit (รับจำนวน)  -> Deposited x, Balance = ...
2 = Withdraw (รับจำนวน) -> Withdrew x, Balance = ...
3 = Balance             -> Balance = ...
4 = Exit                -> Goodbye

ตัวอย่าง
Input:
1
500
2
200
3
4
Output:
Deposited 500, Balance = 500
Withdrew 200, Balance = 300
Balance = 300
Goodbye
