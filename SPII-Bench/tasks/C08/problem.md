# Algorithm #23 — Binary Search

Language: C (C11, gcc)

## Problem statement (as given to students)

Algorithm #23 — Binary Search

รับจำนวน n แล้วตามด้วยตัวเลข n ตัว (เรียงจากน้อยไปมากแล้ว) และค่าที่ต้องการค้นหา พิมพ์ตำแหน่ง index (เริ่มที่ 0) หรือ Not found

ตัวอย่าง
Input:
5
1 3 5 7 9
7
Output:
Found at index 3

## Example test

Input (stdin):
```
5
1 3 5 7 9
7
```
Expected output must contain:
```
Found at index 3
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
