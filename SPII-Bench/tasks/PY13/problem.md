# Grade Evaluator #3 — Class Summary

Language: Python 3

## Problem statement (as given to students)

Grade Evaluator #3 — Class Summary

รับจำนวนนักเรียน n แล้วตามด้วยคะแนน n ตัว จากนั้นสรุป:
จำนวนที่ผ่าน (>=50), จำนวนที่ตก, ค่าเฉลี่ย (ทศนิยม 2 ตำแหน่ง), คะแนนสูงสุด

รูปแบบ Output :
Passed = ...
Failed = ...
Average = ...
Highest = ...

ตัวอย่าง
Input:
5
80
45
60
30
95
Output:
Passed = 3
Failed = 2
Average = 62.00
Highest = 95

## Example test

Input (stdin):
```
5
80
45
60
30
95
```
Expected output must contain:
```
Passed = 3
Failed = 2
Average = 62.00
Highest = 95
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
