# Grade Evaluator #2 — Letter Grade

Language: Python 3

## Problem statement (as given to students)

Grade Evaluator #2 — Letter Grade

แปลงคะแนนเป็นเกรดตัวอักษร
A : 80-100, B : 70-79, C : 60-69, D : 50-59, F : 0-49

รูปแบบ Input : คะแนน (จำนวนเต็ม)
รูปแบบ Output : เกรด A/B/C/D/F

ตัวอย่าง
Input:
85
Output:
A

## Example test

Input (stdin):
```
85
```
Expected output must contain:
```
A
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
