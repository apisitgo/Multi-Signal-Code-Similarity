# Algorithm #30 — Divisors of a Number

Language: C (C11, gcc)

## Problem statement (as given to students)

Algorithm #30 — Divisors of a Number

รับจำนวนเต็มบวก n แล้วพิมพ์ตัวหารทั้งหมดของ n เรียงจากน้อยไปมาก คั่นด้วยช่องว่าง

ตัวอย่าง
Input:
12
Output:
1 2 3 4 6 12

## Example test

Input (stdin):
```
12
```
Expected output must contain:
```
1 2 3 4 6 12
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
