# Basic Calculator #1 — Add Two Numbers

Language: C (C11, gcc)

## Problem statement (as given to students)

Basic Calculator #1 — Add Two Numbers

เขียนโปรแกรมรับจำนวนเต็ม 2 จำนวน แล้วแสดงผลรวม

รูปแบบ Input : จำนวนเต็ม a และ b (บรรทัดละตัว หรือเว้นวรรค)
รูปแบบ Output : ผลรวม a + b

ตัวอย่าง
Input:
3
5
Output:
8

## Example test

Input (stdin):
```
3
5
```
Expected output must contain:
```
8
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
