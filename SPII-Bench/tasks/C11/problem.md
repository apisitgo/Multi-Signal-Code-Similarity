# Algorithm #22 — Bubble Sort

Language: C (C11, gcc)

## Problem statement (as given to students)

Algorithm #22 — Bubble Sort

รับจำนวน n แล้วตามด้วยตัวเลข n ตัว แล้วเรียงจากน้อยไปมากด้วย Bubble Sort พิมพ์คั่นด้วยช่องว่าง

ตัวอย่าง
Input:
5
5 2 9 1 7
Output:
1 2 5 7 9

## Example test

Input (stdin):
```
5
5 2 9 1 7
```
Expected output must contain:
```
1 2 5 7 9
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
