# Algorithm #18 — Armstrong Number

Language: Python 3

## Problem statement (as given to students)

Algorithm #18 — Armstrong Number

รับจำนวนเต็ม n แล้วตรวจว่าเป็นเลข Armstrong หรือไม่ (ผลรวมของแต่ละหลักยกกำลังจำนวนหลัก = ตัวมันเอง เช่น 153 = 1^3+5^3+3^3)

ตัวอย่าง
Input:
153
Output:
Armstrong
