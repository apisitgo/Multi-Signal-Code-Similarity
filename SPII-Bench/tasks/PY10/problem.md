# Algorithm #21 — Second Largest in Array

Language: Python 3

## Problem statement (as given to students)

Algorithm #21 — Second Largest in Array

รับจำนวน n แล้วตามด้วยตัวเลข n ตัว แล้วหาค่าที่มากเป็นอันดับสอง (ค่าที่ไม่ซ้ำกัน)

ตัวอย่าง
Input:
5
10 20 20 8 15
Output:
Second largest = 15

## Example test

Input (stdin):
```
5
10 20 20 8 15
```
Expected output must contain:
```
Second largest = 15
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
