# Algorithm #7 — GCD (Greatest Common Divisor)

Language: Python 3

## Problem statement (as given to students)

Algorithm #7 — GCD (Greatest Common Divisor)

รับจำนวนเต็มบวก 2 จำนวน แล้วหา ห.ร.ม. ด้วยวิธี Euclid

ตัวอย่าง
Input:
48 18
Output:
6

