# Simple Bank Account #1 — One Transaction

Language: Python 3

## Problem statement (as given to students)

Simple Bank Account #1 — One Transaction

รับยอดเงินตั้งต้น, ประเภทรายการ (D = ฝาก, W = ถอน), และจำนวนเงิน
แล้วแสดงยอดคงเหลือใหม่

รูปแบบ Input : balance  op(D/W)  amount
รูปแบบ Output : Balance = ...

ตัวอย่าง
Input:
1000
D
250
Output:
Balance = 1250

## Example test

Input (stdin):
```
1000
D
250
```
Expected output must contain:
```
Balance = 1250
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
