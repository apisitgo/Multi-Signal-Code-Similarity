# Algorithm #27 — Fibonacci Series

Language: C (C11, gcc)

## Problem statement (as given to students)

Algorithm #27 — Fibonacci Series

รับจำนวน n แล้วพิมพ์ลำดับฟีโบนักชี n พจน์แรก เริ่มจาก 0 1 คั่นด้วยช่องว่าง

ตัวอย่าง
Input:
8
Output:
0 1 1 2 3 5 8 13

## Example test

Input (stdin):
```
8
```
Expected output must contain:
```
0 1 1 2 3 5 8 13
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
