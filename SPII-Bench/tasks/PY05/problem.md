## Problem statement (as given to students)

Algorithm #5 — Prime Number Check

รับจำนวนเต็ม n แล้วตรวจว่าเป็นจำนวนเฉพาะหรือไม่ (พิมพ์ Prime / Not prime)

ตัวอย่าง
Input:
13
Output:
Prime
