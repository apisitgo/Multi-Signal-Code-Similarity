# Geometry Area #1 — Rectangle

Language: C (C11, gcc)

## Problem statement (as given to students)

Geometry Area #1 — Rectangle

รับความกว้างและความสูงของสี่เหลี่ยมผืนผ้า แล้วแสดงพื้นที่และเส้นรอบรูป

รูปแบบ Input : width  height
รูปแบบ Output :
Area = ...
Perimeter = ...

ตัวอย่าง
Input:
4
6
Output:
Area = 24
Perimeter = 20

## Example test

Input (stdin):
```
4
6
```
Expected output must contain:
```
Area = 24
Perimeter = 20
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
