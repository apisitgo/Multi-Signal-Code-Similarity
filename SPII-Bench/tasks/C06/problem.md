# Algorithm #14 — Sum and Average of Array

Language: C (C11, gcc)

## Problem statement (as given to students)

Algorithm #14 — Sum and Average of Array

รับจำนวน n แล้วตามด้วยตัวเลข n ตัว แล้วหาผลรวมและค่าเฉลี่ย (ทศนิยม 2 ตำแหน่ง)

ตัวอย่าง
Input:
5
10 20 30 40 50
Output:
Sum = 150
Average = 30.00

## Example test

Input (stdin):
```
5
10 20 30 40 50
```
Expected output must contain:
```
Sum = 150
Average = 30.00
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
