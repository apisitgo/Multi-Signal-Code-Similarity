# Loops and Patterns #2 — Multiplication Table

Language: Python 3

## Problem statement (as given to students)

Loops and Patterns #2 — Multiplication Table

รับจำนวนเต็ม n แล้วพิมพ์สูตรคูณแม่ n ตั้งแต่ 1 ถึง 12

รูปแบบ Output (แต่ละบรรทัด) : n x i = ผลคูณ

ตัวอย่าง
Input:
7
Output:
7 x 1 = 7
7 x 2 = 14
...
7 x 12 = 84

## Example test

Input (stdin):
```
7
```
Expected output must contain:
```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
7 x 11 = 77
7 x 12 = 84
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
