# Basic Calculator #2 — Simple Calculator

Language: C (C11, gcc)

## Problem statement (as given to students)

Basic Calculator #2 — Simple Calculator

รับตัวเลข a, เครื่องหมาย op (+ - * /), และตัวเลข b แล้วคำนวณ a op b
- ถ้าหารด้วย 0 ให้พิมพ์ : Error: division by zero
- ถ้า op ไม่ถูกต้อง ให้พิมพ์ : Error: invalid operator
- ถ้าผลลัพธ์เป็นจำนวนเต็มพอดี ให้แสดงแบบไม่มีจุดทศนิยม

รูปแบบ Input : a  op  b
รูปแบบ Output : ผลลัพธ์

ตัวอย่าง
Input:
6
*
7
Output:
42

## Example test

Input (stdin):
```
6
*
7
```
Expected output must contain:
```
42
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
