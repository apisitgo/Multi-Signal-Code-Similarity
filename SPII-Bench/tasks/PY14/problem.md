# Basic Calculator #3 — Multi-Number Stats

Language: Python 3

## Problem statement (as given to students)

Basic Calculator #3 — Multi-Number Stats

รับจำนวน n แล้วตามด้วยตัวเลข n ตัว จากนั้นแสดง ผลรวม ค่าเฉลี่ย ค่ามากสุด และค่าน้อยสุด

รูปแบบ Input : n แล้วตามด้วยตัวเลข n ตัว
รูปแบบ Output :
Sum = ...
Average = ...
Max = ...
Min = ...

ตัวอย่าง
Input:
5
10
20
30
40
50
Output:
Sum = 150
Average = 30
Max = 50
Min = 10

## Example test

Input (stdin):
```
5
10
20
30
40
50
```
Expected output must contain:
```
Sum = 150
Average = 30
Max = 50
Min = 10
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.py` in this folder.
