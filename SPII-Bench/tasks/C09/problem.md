# Loops and Patterns #3 — Star Pyramid

Language: C (C11, gcc)

## Problem statement (as given to students)

Loops and Patterns #3 — Star Pyramid

รับความสูง n แล้วพิมพ์พีระมิดดาวจัดกึ่งกลาง
แถวที่ i มีช่องว่างนำหน้า (n - i) ช่อง และมีดาว (2*i - 1) ดวง

ตัวอย่าง
Input:
4
Output:
   *
  ***
 *****
*******

## Example test

Input (stdin):
```
4
```
Expected output must contain:
```
*
  ***
 *****
*******
```

The program reads from standard input and writes to standard output. Start from the starter file `starter.c` in this folder.
